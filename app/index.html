    Get your API keys

    Skim needs two free keys. Add both in Settings — they stay on this device only.

    1️⃣ YouTube Transcript (RapidAPI)

    1. Visit rapidapi.com/…/youtube-transcript3
    2. Sign in to RapidAPI.
    3. Subscribe (free plan: 100 requests/month).
    4. Copy your API key.
    5. Paste it in Skim → Settings.

    2️⃣ Gemini

    1. Visit aistudio.google.com/api-keys
    2. Create a new API key.
    3. Copy the key.
    4. Paste it in Skim → Settings.

    ✅ Setup complete! Great job 👏
